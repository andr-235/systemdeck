# Категориальная палитра плиток treemap — исключение из токенов

EPIC 4 (Storage Analyzer), страница Storage. Плиткам treemap нужны различимые цвета по папкам: монохром не различается (жалоба пользователя), а в токенах `--sd-color-*` категориального набора нет — только семантические цвета (primary, success, destructive).

## Considered Options

- **Только токены `--sd-color-*`**: отклонено — семантические цвета несут смысл (успех/ошибка), их повторное использование для папок вводило бы в заблуждение; различимых нейтральных оттенков в токенах нет.
- **Радуга по хешу пути** (`hsl(случайный hue 55% 78%)`): отклонено — кричащие пастели, жалоба пользователя.
- **Монохромная синяя шкала**: отклонено — все плитки одинаковые, жалоба пользователя.
- **Цвет по категории типа файла** (стиль WinDirStat): отклонено — узлы-каталоги не несут категории (классификация в Main только для файлов, ADR 0013).

## Consequences

- Исключение из CON-003 плана `plan/refactor-storage-page-1.md` строго в границах `treemapColor.ts`: 12 приглушённых цветов, стабильный цвет папки по хешу пути, затемнение по доле размера; «Файлы» — нейтральный сине-серый, недоступные — серые пунктирные.
- Палитра живёт в одной константе `PALETTE` — смена набора правится в одном месте.
- Остальной Renderer по-прежнему только на токенах `--sd-color-*`.
