# Process termination through the standard invoke channel

В EPIC 3 (модуль «Процессы») терминация процесса реализуется как обычный invoke-канал `systemdeck:process:terminate` с результатом `IpcResult`, исполняемый в Main через `Stop-Process -Force`. Несмотря на деструктивность, отдельного «privileged» канала нет: безопасность обеспечивается не изоляцией контракта, а тем, что Renderer инициирует убийство только после явного подтверждения пользователем (модальный диалог), а Main логирует каждую терминацию в Application Log.

Защищённость процесса (`protected: true`) вычисляется в Main и кладётся в `ProcessEntry` push-контракта; Renderer лишь читает флаг и блокирует кнопку, никогда не классифицируя процессы сам. Это остаётся в силе, потому что классификация — источник правды Main, а Renderer не должен принимать process-management решения.
